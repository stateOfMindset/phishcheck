title: What to do after clicking a suspicious link
source_type: general

## First, do not panic

Opening a phishing link is common and, on an up-to-date device, usually not harmful by itself. The danger mostly comes from what happens next: typing a password or code into the page, downloading and opening a file, or allowing the page to install something or send notifications. Work out which of these happened, because the next steps depend on it.

## If you only opened the page

1. Close the tab or browser without typing anything into the page.
2. Do not go back to the page to "check" it.
3. Make sure your browser and operating system are up to date.
4. Report the message so others can be warned and the link can be blocked.

If you typed nothing, downloaded nothing and approved nothing, no further action is usually needed beyond reporting.

## If something was downloaded

Do not open the downloaded file. Delete it, and empty the downloads folder or recycle bin. Run a full scan with your antivirus or the built-in security tool on your device. If you already opened the file, follow the guidance for a suspicious attachment that was opened, and tell your IT helpdesk.

## If the page asked for permissions

Some phishing pages ask you to allow notifications, install a browser extension, or install an app or "security update". If you allowed any of these, remove the extension or app, block notifications for that site in your browser settings, and report it. Fake notifications can keep pushing scam messages long after you closed the page.

## If you typed a password or code

Opening the page is no longer the main issue. Follow the guidance for entering a password on a phishing page straight away, and if you entered an MFA code or approved a sign-in request, treat it as urgent.

## What to watch for afterwards

For the next few days, watch for sign-in alerts you did not cause, password-reset emails you did not request, new MFA prompts, or messages sent from your account that you did not write. Any of these means the account may be compromised and should be reported immediately.
