## About this procedure

Sample procedure written for a course project. It is not an official policy of {{COLLEGE_NAME}}. It applies when a student opened a link from a suspicious message. If a password, MFA code or sign-in approval was also given, use the credential exposure procedure instead, which takes priority.

## Questions to answer first

Before deciding on the next steps, establish:

- Did the page ask for your college username or password, and did you type anything?
- Did you enter an MFA code or approve a sign-in prompt?
- Did anything download, install, or ask for permission (notifications, extensions)?
- Was this on a personal device or a college computer (lab, library)?

## Steps if nothing was entered or downloaded

1. Close the page without typing anything.
2. Report the message to {{HELPDESK}} and mention that you opened the link, with the approximate time.
3. Delete the message.

No password change is required, but changing your password is never harmful if you are unsure whether you typed something.

## Steps if something was downloaded or installed

1. Do not open the file; delete it. If something was installed, disconnect the device from the network.
2. Report to {{HELPDESK}} straight away, with the file name and what happened on screen.
3. On a college computer, stop using it and tell the lab or library staff so the machine can be checked.
4. From a different device, change your college password as a precaution.
